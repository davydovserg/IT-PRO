# АйТи Про

Прототип платформы независимой оценки IT-специалистов: тест по направлениям (Backend, Frontend, DevOps, 1С — по 30 вопросов трёх уровней сложности), сертификат с номером в реестре и QR-кодом, подбор специалистов с помесячной оплатой и калькулятор аудита оклада.

Одна страница без сборки: откройте `index.html` в браузере.
